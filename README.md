# commit-hygiene

A `commit-msg` git hook that removes AI-tool attribution from commit messages,
plus a CI check for commits made without it.

## One-paste setup (for your IDE AI)
Paste this into Claude Code / Cursor / Copilot Chat / any coding assistant on your machine:

````text
Set up the "commit-hygiene" git commit-msg hook on this computer.

1. Clone https://github.com/vbs-0/commit-hygiene into a temporary folder
   (if the clone fails with an auth/404 error, stop and tell me I need access).
2. Check whether `git config --global core.hooksPath` is already set and whether a
   commit-msg file already exists there. If one exists, show me its contents and
   ask before replacing it (install.sh keeps a commit-msg.bak copy).
3. Run `sh install.sh --global` from the cloned folder.
4. Verify: run `sh tests/run.sh` (all lines must start with "ok"), then in a
   throwaway temp repo make a commit whose message contains
   "Co-Authored-By: Claude <noreply@anthropic.com>" and confirm that line is
   gone from `git log -1`.
5. Delete the temporary clone and the throwaway repo.
6. Do not change any other git or editor setting. Report what you did.
````

Only want it in one repo? Replace step 3 with: "`cd` into that repo and run
`sh <path-to-the-clone>/install.sh` (no `--global`)", and do not keep the clone
deleted until after that step.

## What it removes
- `Co-Authored-By:` lines for a tool name (Claude, Devin, Codebuff, Cursor, Codex,
  Gemini, Windsurf, Copilot, Aider, Qwen, ...) or a bot / no-reply tool address
- `Generated with ...` / `Generated by ...` lines naming a tool
- robot-emoji lines that name a tool

Human co-authors are kept. Case-insensitive. Portable (POSIX sh + awk; works in
Git Bash on Windows, macOS, Linux).

## Install
```sh
./install.sh            # this repo only
./install.sh --global   # every repo on this machine
```
Per-repo: commit `.githooks/` and have teammates run `git config core.hooksPath .githooks` once.

## Options
- **Allow-list a human who shares a tool's name:** put their email in
  `allow-coauthors` next to the hook, one per line.
- **Enforce a footer (optional, off by default):** each person chooses their own
  line, e.g. `git config --global commit-hygiene.footer "Authored-By: Their Name"`.
  After the hook strips attribution it appends that line to the message if it is
  not already there. Unset it (`git config --global --unset commit-hygiene.footer`)
  to turn it off.

## CI backstop
`.github/workflows/check-commits.yml` fails a PR whose commits still carry
attribution. Call it from other repos with `uses: vbs-0/commit-hygiene/.github/workflows/check-commits.yml@main`
(the repo must be readable by the calling repo).

## Limits
- A local hook cannot see commits made in the GitHub web UI, or the
  `Co-authored-by:` lines GitHub adds when squash-merging; the CI check covers the first.
- A person literally named Claude/Devin/... is stripped unless allow-listed.

## Test
`sh tests/run.sh`
